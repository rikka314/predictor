# UI 设计指导（继承版）

> 来源：参考 `stratagy/document/UI_DESIGN_GUIDE.md` 的可复用部分  
> 目标：为 Predict 项目提供可执行的 UI 设计清单

## 1. 当前页面重点

Predict 项目当前核心流程是：

1. 上传 CSV
2. 设置阈值
3. 执行预测
4. 查看结果并下载

UI 优化应围绕这 4 步进行，不引入不必要复杂区块。

## 2. 配色建议

建议使用暖色中性背景 + 清晰金融语义色：

- 背景：`#f4f1ea` / `#fffdf8`
- 主文字：`#21303a`
- 主强调：`#2f5d62`
- 警示强调：`#8f3b2e`
- 正向状态：`#27ae60`
- 风险状态：`#c0392b`

## 3. 布局建议

### 3.1 页面结构

- 顶部：标题 + 当前子路径说明（`/predict`）
- 中部：左主操作（上传与参数）+ 右结果预览（可在后续扩展为 split）
- 底部：下载与轻量说明

### 3.2 组件优先级

- 高优先：文件上传、预测按钮、结果下载
- 中优先：阈值与输入校验反馈
- 低优先：附加说明文本

## 4. 文案与状态

- 空态：`请先上传包含数值特征列的 CSV 文件。`
- 处理中：`正在执行预测，请稍候...`（后续可加 spinner）
- 错误：说明失败原因并提示修复动作
- 成功：明确可下载结果文件

## 5. 实施优先级

### Phase 1（已具备）

- 上传、预测、结果预览、下载全链路可用
- 基础主题注入完成

### Phase 2（下一步可做）

- 结果页加入 KPI 摘要（样本数、正类比例、均值分数）
- 统一图表主题（若后续加入可视化）
- 增强错误提示（列缺失、数据类型异常）

### Phase 3（后续扩展）

- 多模型切换（baseline / trained model）
- 历史任务记录与结果回放
- 导出报告页面（HTML/PDF）
